# CRM básico — ejercicio de agentes (desde cero, en la nube)

Este repositorio arranca vacío a propósito: solo contiene las
definiciones de los 8 agentes personalizados en `.claude/agents/`
(planificador, arquitecto-datos, disenador-ux, fullstack, tester,
revisor, documentacion, devops).

El proyecto CRM (dashboard + contactos) todavía no existe aquí — se
va a construir completo dentro de una sesión de Claude Code en la
nube, siguiendo el ciclo completo de los 8 agentes, usando datos
hardcodeados en memoria en vez de una base de datos real.
